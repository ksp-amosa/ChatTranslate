# ChatTranslate 聊天翻譯

《魔獸世界》永恆版本（WoW Forever）的聊天翻譯插件。在聊天訊息旁加上「譯」按鈕，把外文翻成繁體中文；也能把中文回覆翻成英文，直接放進聊天輸入框。翻譯由電腦上的外部工具處理，可使用本機模型或雲端 AI 服務。

> **請從 [Releases](../../releases/latest) 下載發布的 zip，不要直接下載這個儲存庫的原始碼。** 發布的 zip 附有作者簽章，外部工具會驗證；直接下載原始碼可能和簽章不一致。

## 功能

| 功能 | 說明 |
|---|---|
| 翻譯視窗 | 點訊息旁的「譯」，顯示原文與繁體中文譯文，可選取複製 |
| 中文回覆 | 視窗下方常駐回覆欄，輸入中文按 Enter 翻成英文，放進聊天輸入框；再按 Enter 或「送出」發出 |
| 聊天框顯示譯文 | 譯文直接接在訊息後面，保留頻道顏色；物品、任務連結會保留原樣 |
| 外部工具選單 | 設定翻譯服務、加密保存 API 金鑰、檢查環境、從 zip 更新、解除安裝 |

### 支援的翻譯服務（擇一）

- 本機模型（LM Studio 等 OpenAI 相容服務）：免費，聊天內容不離開電腦
- Google Gemini、OpenAI ChatGPT、Anthropic Claude：需要 API 金鑰
- Claude Code：需要 Claude Code 訂閱

## 運作方式

插件無法連網，所以翻譯交給遊戲外的工具，兩邊只透過遊戲允許的方式交換資料：

- **遊戲 → 外部工具**：插件在畫面最左上角畫一條 1 像素高的色塊條，外部工具擷取遊戲視窗最上方 2 列畫面讀出內容。
- **外部工具 → 遊戲**：外部工具寫入插件資料夾內的快取圖片（`slots`），插件讀取圖片的寬高還原文字。遊戲只在登入或 `/reload` 時掃描檔案，所以每次 `/reload` 有固定數量的快取（預設 5000）。

不讀取、不修改遊戲記憶體，不注入程式，不模擬鍵盤滑鼠。本插件未經 Blizzard 審核或認可，是否使用請自行評估。

## 系統需求

- Windows 10 / 11
- [uv](https://github.com/astral-sh/uv)：外部工具用它準備 Python 環境，不需要另外安裝 Python。第一次執行時若找不到 uv，可選擇自動安裝或自行安裝。

## 安裝

1. 從 [Releases](../../releases/latest) 下載 `ChatTranslate-版本.zip`。
2. 解壓縮到遊戲目錄的 `Interface\AddOns`，完全關閉遊戲後重新開啟。
3. 雙擊 `ChatTranslate\Tool\ChatTranslate.bat`：
   - 選「2. 設定翻譯方式」選擇服務並測試連線。
   - 雲端服務選「3. 設定 API 金鑰」。
   - 選「1. 啟動翻譯工具」，建議背景執行。
4. 第一次啟動外部工具後，在遊戲輸入 `/reload`。

## 更新

下載新版 zip（不用解壓縮），雙擊 `ChatTranslate.bat` 選「7. 更新插件」。工具會驗證作者簽章後才更新，並先備份目前的版本。

## 檔案驗證

- 作者金鑰指紋：`A413-0880-762B-7502-43E4`
- 每個版本的 zip SHA-256 寫在該版的 Release 說明裡。下載後可在 PowerShell 執行 `Get-FileHash .\ChatTranslate-版本.zip` 核對。
- 選單「6. 檢查執行環境」與「7. 更新插件」都會驗證簽章；檔案被修改或重新打包時會標示警告或拒絕更新。

## 安全性與隱私

- 不需要系統管理員權限。
- 網路只連到你選的翻譯服務；第一次執行時 uv 會下載 Python 與套件。不回傳使用紀錄。
- API 金鑰以 Windows DPAPI 加密保存在 `%LOCALAPPDATA%\ChatTranslate`，只有同一台電腦的同一個 Windows 帳號能解開。
- 翻譯紀錄只存在本機；使用雲端服務時，要翻譯的內容會送到該服務。
- 選單「8. 解除安裝」可逐項刪除所有資料。

## 相容性

「譯文接在訊息後面」只在遊戲原生聊天框測試確認。搭配會重做聊天框的 UI 插件時，可能接不上或按鈕位置偏移；翻譯視窗不受影響，可在設定中改用翻譯視窗。
